# 素材与整理说明

## 收录范围

展示仓库从原始项目中选取以下内容：

| 内容 | 仓库位置 | 处理方式 |
| --- | --- | --- |
| 游戏入口、脚本与样式 | `game/` | 保留原文件，未改动游戏逻辑 |
| 五张章节背景及现有图像目录 | `game/images/` | 保留原文件及相对路径 |
| 十份运行音频 | `音频/` | 仅收录代码明确引用的 WAV 文件 |
| 完整剧本与人物设定 | `docs/design/` | 保留原文，集中归档 |
| 实机截图 | `docs/screenshots/` | 从整理后的版本实际运行时截取 |
| README 设定图 | `docs/illustrations/` | 人物和物件展示图，含角标修复与全家福重绘 |
| 中文说明与运行记录 | 根目录及 `docs/` | 为公开展示补写 |

游戏的 44 份代码、页面、样式、图像和音频文件的 SHA-256 摘要保存在 [source-manifest.json](source-manifest.json) 中，用于核对运行文件是否发生变化。该清单不包含新增文档和截图。

## 原目录保留的内容

原项目未被覆盖。参考视频、参考图片、参考文档、参考音频、大量梦核参考图、重复原画、未使用的音乐文件、PDF 处理依赖和开发工具配置均保留在原始目录，未放入公开仓库。

原根目录的 `package.json` 用于 PDF 文本处理，并非游戏的运行依赖，因此这里不要求执行 `npm install`。原先与个人部署项目绑定的配置也未带入展示版。

## 相对路径

音频加载器使用 `../音频/文件名.wav`。为保持原代码不变，仓库继续采用 `game/` 与 `音频/` 同级的结构。

本地运行或静态托管时，应将整个仓库作为站点根目录，使用 `/game/` 作为游戏入口。不要仅复制 `game/` 子目录，也不要随意重命名音频目录。

## 素材与授权记录

当前项目资料没有附带覆盖所有代码、文本、美术与音频的统一许可证。本次整理未新增开源许可证，也未将素材声明为可自由商用。

运行代码中将预制背景称为 AI 原画，但原目录未附完整的逐项生成工具、提示词和授权记录。因此本仓库不推断具体生成平台或素材授权来源。游戏目录中的原始图像、音频和剧本文本保持原项目内容；如需单独复用，请核对相应素材的授权。

全家福重绘使用内置 imagegen 工具，以 [童年林瑜](illustrations/linyu-child.png) 为人物身份参考，以原展示版为相框与客厅环境参考。提示要求：相片中是同一个穿粉色短袖的 8 岁中国女孩林瑜，坐在中国父亲与中国母亲中间，保持她的五官、发型、年龄和开心笑容；一家三口自然微笑，呈现 2008 年前后普通中国家庭合影的质感；保留旧相框、玻璃茶几、暖色午后光线与方形构图，同步更新桌面倒影，不添加文字或水印。重绘结果保存为 `docs/illustrations/family-photo.png`。
