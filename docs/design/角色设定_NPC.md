## 王奶奶

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | 王桂芳 |
| **年龄** | 68 岁 |
| **身份** | 林瑜家楼下的邻居，退休纺织厂女工 |
| **外貌** | 花白短发，常穿碎花衬衫和深色长裤。手里永远拿着一把蒲扇，即使不在夏天。背微微佝偻，但走路很利索。 |
| **性格** | 慈祥、唠叨、固执的热心肠。喜欢给人塞吃的，对谁都叫「小X」。她的世界很小——儿子在北京一年回来一次，她把邻里都当成了自己的孩子。 |
| **与林瑜的关系** | 从小看着她长大的邻居奶奶。小时候林瑜爸妈加班，常去王奶奶家蹭饭。王奶奶做的蒸红薯是林瑜童年最甜的记忆。 |
| **梦核设定** | 王奶奶的对话有强烈的「重复感」——她会反复问同样的问题，给出同样的回答。这种重复不是 bug，而是梦核的核心美学：被困在时间里的灵魂。她的钟停在了 2008 年。 |

### 完整对话树

#### 触发条件：在林瑜家楼下/楼道中遇到

```
[第一次见面]
王奶奶：（眯起眼睛打量）哟，这不是小林瑜吗？长这么高了！
林瑜：奶奶好……
王奶奶：吃饭了没？来来来，奶奶刚蒸了红薯，还热乎着呢。
  → 选项 A：接过红薯（好感+1）
  → 选项 B：谢谢奶奶，我不饿

[选项 A - 接过红薯]
王奶奶：（笑眯了眼）多吃点，看你瘦的。你小时候可爱吃这个了，
每次都吃得满嘴都是，你妈说你也不听。
林瑜：（咬了一口）……还是那个味道。
王奶奶：味道能变吗？红薯就是红薯。人就不一样了，人变得快。

[选项 B - 婉拒]
王奶奶：（有些失落）哦……那行，奶奶给你留着。啥时候想吃
了就来。奶奶家门没锁过。

[第二次见面]
王奶奶：（像第一次一样笑着）哟，小林瑜！吃饭了没？
林瑜：奶奶，您刚才问过我了……
王奶奶：（愣了愣，然后笑）是吗？奶奶记性不好了。那……吃了就好，
吃了就好。

[第三次见面（重复加深）]
王奶奶：（坐在楼下的长椅上，看着远处）你小时候最爱吃我家的
蒸红薯了……那时候你才这么高（比划到腰际），一晃眼……
林瑜：奶奶，您还好吗？
王奶奶：（没有看她）我好啊。我能有什么不好的。就是……有时候
想不起来今天是哪一年了。

[告别/离开章节时]
王奶奶：（从窗台探出头来）小林瑜，有空常回来看看啊！
奶奶给你留着红薯呢。别忘了——别忘了回来。
```
### 行为逻辑
- 她会在固定的时间出现在固定的地点（楼道口、楼下长椅、厨房窗口）
- 不管玩家选择什么对话选项，她最终的回应都会收敛到同一句话：「吃了就好」
- 如果玩家反复与她对话，会发现她的话题池有限——翻来覆去就是红薯、儿子、天气
- **梦核隐喻**：王奶奶代表那些被时间留在原地的人。她是 2008 年的一部分，无法跟随你来到 2026。

## 周小萌（童年最好的朋友）

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | 周小萌 |
| **年龄** | 8 岁（2008 年） |
| **身份** | 林瑜的小学同班同学，最好的朋友 |
| **外貌** | 扎着双马尾，门牙掉了一颗，笑起来漏风。膝盖上永远有新的创可贴。穿着粉色的 T 恤和蓝色短裤。 |
| **性格** | 活泼、话多、胆子大。是那个会拉着林瑜去做「冒险」事情的人——翻墙捡羽毛球、跟男生比赛爬树、趁老师不在偷吃零食。在 8 岁的林瑜眼中，周小萌是世界上最勇敢的人。 |
| **与林瑜的关系** | 最好的朋友。她们约定过长大了要住在同一个小区，做一辈子的好朋友。但周小萌家在 2008 年底搬去了深圳，之后慢慢断了联系。 |
| **梦核设定** | 周小萌是林瑜记忆中「2008 年夏天」最明亮的部分。在梦核世界里，她永远 8 岁，永远在那个暑假等着林瑜。 |

### 完整对话树

#### 触发条件：在林瑜家楼下喊她出去玩

```
[喊林瑜下楼]
周小萌：（双手拢在嘴边，朝楼上喊）林——瑜——！你怎么
还没好啊！太阳都要下山啦！

林瑜：（跑下楼）来了来了！
周小萌：（上下打量）你穿这个啊？今天要去冒险的，你穿拖鞋怎么行！
  → 选项 A：回去换鞋
  → 选项 B：管它呢，走吧！

[选项 A - 回去换鞋]
周小萌：快点啊！我在楼下等你！数到一百你还不来我就自己走了！
（开始数数）一、二、三……
林瑜：（跑上楼换鞋，听到她在楼下认真地数着数）

[选项 B - 拖鞋也行]
周小萌：（大笑）不愧是林瑜！那我们走吧！

[一起去小卖部的路上]
周小萌：（边走边踢石子）你暑假作业写多少了？
林瑜：写了一页……
周小萌：哈哈哈我也是！我妈妈说开学前一周再写也来得及。
          我妈妈说暑假就是用来玩的！
          
[在小卖部门口]
周小萌：（趴在冰柜上看）今天吃哪个呢……老冰棍还是绿舌头？
林瑜：绿舌头吧，可以玩很久。
周小萌：（对老板）叔叔，两个绿舌头！
（转头对林瑜小声说）我请客！我考了双百，我妈奖励了我五块钱！
          不过你别跟别人说啊，不然他们都让我请。

[吃着冰棍往回走]
周小萌：林瑜，你说我们长大了会变成什么样的人啊？
  → 选项 A：我想当画家
  → 选项 B：我想当科学家
  → 选项 C：我不知道

[选项 A - 画家]
周小萌：好！那你画我！等我变成大明星的时候，你给我画海报！

[选项 B - 科学家]
周小萌：哇——那你以后是不是要研究那种……时间机器什么的？
          到时候你来找我玩啊，不管我在哪！

[选项 C - 不知道]
周小萌：（满不在乎）没关系啦！我也不知道！我妈妈说长大
          了就知道了。我妈什么都知道。

[告别时]
周小萌：林瑜，明天我们还出来玩吧！去那个新开的游乐场！
          听说有旋转木马！我还没坐过呢！
林瑜：好！
周小萌：拉勾！
（两人拉勾）
周小萌：拉勾上吊一百年不许变！谁变谁是小狗！
```
### 行为逻辑
- 她会在固定的路线活动——林瑜家楼下 → 小卖部 → 学校后墙 → 家
- 她会主动拉着林瑜走，玩家不需要做太多选择，跟着她就行
- 她的快乐是真实的，她说的每一句话都在告诉林瑜：你看，8 岁的生活是这样的
- **梦核提示**：如果你跟她提起「未来」或「搬家」，她的笑容会有一瞬间的停顿，然后若无其事地岔开话题——因为在这个世界里，「未来」和「离开」是不存在的。

## 小卖部老板（陈叔）

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | 陈德发 |
| **年龄** | 45 岁（2008 年） |
| **身份** | 学校门口小卖部老板 |
| **外貌** | 穿着白色背心，外面罩一件褪色的蓝大褂。戴着老花镜，看东西的时候会把眼镜往下拉，从镜框上面看人。手指夹着一根烟（永远不点着）。头发有点油，好像很长时间没洗。 |
| **性格** | 表面凶，实际心软。对小孩总是板着脸说「少买点垃圾食品」，但从来没拒绝过任何一个赊账的小孩。嘴里叼着烟跟每个来接孩子的家长唠嗑。 |
| **与林瑜的关系** | 「陈叔的小卖部」是林瑜童年记忆中最鲜艳的一部分。五毛一包的辣条、一毛一顆的西瓜糖、还有那种刮奖卡——陈叔会在她中了五毛的时候笑着说「今天运气不错」。 |
| **梦核设定** | 陈叔的店里循环播放着 2008 年的新闻和歌曲。电视里在播北京奥运会的筹备进展，收音机里放着《北京欢迎你》。他永远在整理货架，但那排货架永远也整理不完。 |

### 完整对话树

#### 触发条件：进入小卖部

```
[进店]
陈叔：（从老花镜上方看过来）哟，小林瑜来了。今天要点什么？
  → 选项 A：买辣条
  → 选项 B：买冰棍
  → 选项 C：随便看看

[选项 A - 买辣条]
林瑜：陈叔，我要一包卫龙。
陈叔：（从货架上拿了一包递过来）五毛。我跟你说，这个新出的
      口味可辣了，别怪我没提醒你。
林瑜：没事，我能吃辣。
陈叔：你上次也说能，喝了半瓶水。

[选项 B - 买冰棍]
林瑜：陈叔，我要一个绿舌头。
陈叔：（打开冰柜翻找）绿舌头……今天卖得真好，就剩最后一个了。
      你运气好。（递过来）五毛。

[选项 C - 随便看看]
陈叔：随便看看可以啊，别碰那个玻璃柜台，上面有油。

[买东西后]
（陈叔从抽屉里找零，抽屉里有几张皱巴巴的钞票和很多硬币）
陈叔：两块钱找你……一块五。拿好了啊。
      回去别让你妈知道又买零食了，回头她又要来说我。

[聊起生意]
林瑜：陈叔，今天生意怎么样？
陈叔：（推了推眼镜）就那样吧。对面开了个超市，比我这儿大，
      东西也多。现在的小孩都喜欢去那边了。
      （顿了顿）不过还是有人会来的。习惯了的老顾客，还是会来的。

[关于2008年]
（电视里在播新闻）
陈叔：（抬头看了一眼电视）北京奥运会还有两个月了……你说
      咱们国家什么时候也能办一次啊？
      （忽然自嘲地笑了一下）哦，今年就是啊。我老糊涂了。

[告别]
林瑜：陈叔，我走了。
陈叔：嗯，下次再来。（低头继续整理货架，忽然抬头）对了——
      告诉小萌，她上回那个刮奖卡中了五毛，还没来领呢。
```
### 行为逻辑
- 他永远站在柜台后面，不会离开小卖部
- 他的电视永远不会关机，永远在播 2008 年的新闻
- 如果你买零食，他会照例叮嘱「别让你妈知道」
- **梦核提示**：关于「对面超市」的对话是时间裂缝——2008 年的对面没有超市。那是多年之后的事，但陈叔已经「知道」了。

## 李老师

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | 李志远 |
| **年龄** | 34 岁（2008 年） |
| **身份** | 林瑜的小学班主任，语文老师 |
| **外貌** | 中等身材，戴黑框眼镜。总是穿着白衬衫和深色长裤，衬衫最上面一颗扣子永远扣着。手里拿着一个已经磨破边的教案本，右上角画着一朵小红花。 |
| **性格** | 严肃但不严厉。批评人的同时会叹气——那种「老师也是为你好」的叹气。对好学生和差学生一样耐心。口袋里永远有糖，用来哄哭了一年级新生。 |
| **与林瑜的关系** | 李老师是林瑜最喜欢的老师之一。他曾在林瑜的作文本上写过一段很长的批语：「你有一个很细腻的灵魂，不要弄丢了它。」林瑜一直留着那本作文本。 |
| **梦核设定** | 李老师出现在空无一人的教室里。他在黑板前写着什么，但你走过去的时候，黑板上只有一片模糊。他的手表停了——停在下午三点五十分。 |

### 完整对话树

#### 触发条件：进入小学教室

```
[在教室相遇]
（推开教室门，李老师正站在讲台边，低头看教案）
李老师：（抬头，没有丝毫惊讶）哦，你来了。
林瑜：李老师……您怎么在这里？
李老师：今天是周六，我不该在这里吗？
         （放下教案）你来学校做什么？暑假作业忘拿了？

  → 选项 A：我……就是回来看看
  → 选项 B：我也不知道为什么会来这里

[选项 A - 回来看看]
李老师：（点点头）好。回来看看好。人总要记得自己是从哪里出发的。

[选项 B - 不知道]
李老师：（看了你一会儿）不知道也没关系。有时候不需要知道
        为什么，只需要知道——你已经在这里了。

[聊起作文]
（李老师翻开教案本，里面夹着一张泛黄的作文纸）
李老师：你还记得你写过一篇作文吗？题目是《二十年后的我》。
林瑜：（想了想）好像……写过。
李老师：你写的是——「二十年后我二十五岁，应该已经实现了
        所有的梦想。」
        （轻轻笑了一下）你那时候可真敢写啊。

  → 选项 A：我现在活成了作文里没写到的那种人
  → 选项 B：我已经忘了那篇作文写了什么

[选项 A - 讽刺的现实]
李老师：（沉默了一会儿）作文嘛……写的是愿望，不是预言。
        没人规定二十年后的你一定要是什么样子。
        （把作文纸折好放回教案本）但我还是觉得——那个写
        作文的小女孩，她现在也一定在某个地方好好地活着。

[选项 B - 忘记了]
李老师：忘了也好。有些东西忘记了，才会在某一天突然想起来。
        到时候——你会惊喜的。原来我曾经是这样想的。

[告别]
李老师：要走了？
林瑜：嗯……谢谢您，李老师。
李老师：谢我做什么。我什么都没做。
        （低头看教案，又抬头）对了——那篇作文我给你打了
        「优秀」。我一直觉得，你值得这个评价。不管是二十年前，
        还是现在。
```
### 行为逻辑
- 他只在教室出现，不会离开教学楼
- 他的动作是循环的——写板书 → 看教案 → 抬头看你 → 继续写板书
- 教室里的时间永远是下午三点五十分，阳光从西边的窗户斜射进来
- **梦核提示**：如果你看向黑板，会看到上面写着一行字：「你可以回去，但那里已经没有人了。」再看第二眼的时候，字已经不见了。

## 妈妈（赵秀兰）- 回忆语音

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | 赵秀兰 |
| **年龄** | 34 岁（2008 年） |
| **身份** | 林瑜的妈妈，超市收银员 |
| **外貌** | 在 2008 年的记忆中：烫着卷发，穿碎花连衣裙，很爱笑，笑声响亮。手腕上戴着一块老式电子表。 |
| **性格** | 刀子嘴豆腐心的典型中国母亲。嘴上总在念叨，行动上总在付出。她的爱藏在「多穿件衣服」「作业写完了吗」「碗放在水池里我来洗」这些日常短语里。 |
| **与林瑜的关系** | 林瑜和妈妈的关系是「报喜不报忧」——她很少跟妈妈说自己工作上的不顺心，因为妈妈会说「太累了就回来吧，妈养你」，而她最怕听到的就是这句话。在 2008 年这个夏天，妈妈还是一个年轻的、嗓门很大的、系着围裙在厨房里哼歌的女人。 |
| **梦核设定** | 妈妈是这个梦核世界里最大的温暖，也是最深的「裂缝」。因为林瑜知道——在 2026 年，妈妈的腰已经不好了，头发白了一大半。而这个 2008 年的妈妈，还那么年轻。 |

### 完整对话树

#### 触发条件：妈妈没有实体，只有从各个角落传来的声音

```
[午睡醒来时 - 从厨房传来]
妈妈的声音：（伴随着锅铲翻炒的声音）醒了？西瓜在冰箱里，
            自己切啊。别切到手。
（林瑜走到厨房门口——厨房里没有人。灶台上的火开着，锅里
 在炒着什么，但没有人）

[准备出门时]
妈妈的声音：（从客厅传来）零花钱在抽屉里，自己拿。
            别买那些垃圾食品，听到了没？
林瑜：知道了——
妈妈的声音：（远了一些）晚饭前回来！今天做了你爱吃的糖醋排骨！

[看电视时]
妈妈的声音：（从阳台传来）作业写完了吗就开电视？
林瑜：写完了——
妈妈的声音：（脚步声走近）我看看……（停顿）你这个字写得
            越来越潦草了。以后考试要扣卷面分的。
林瑜：哦……
妈妈的声音：（叹了口气，但伸手摸了摸你的头）算了，放假了，
            今天就让你看吧。

[傍晚 - 声音变得更远]
妈妈的声音：（像是从很远的地方传来）吃饭了——去洗手！
（林瑜转身——饭桌上已经摆好了碗筷，两副。但只有她一个人。）

[深夜（如果玩家还不睡）]
妈妈的声音：（低低的，像是自言自语）这孩子……怎么还不睡。
（然后脚步声轻轻走近，有什么东西被轻轻地盖在了身上） 
```
### 行为逻辑
- 妈妈永远不会出现在视线中——只有她的声音，她的痕迹（留的字条、做好的饭、洗干净的衣服）
- 声音的「位置」会变化，但永远在下一个转角、另一扇门后面
- 她是 2008 年的世界对林瑜最温柔的挽留
- **梦核提示**：如果玩家尝试寻找妈妈的声音来源，会发现声音永远从背后传来。你永远转不到她的方向。

## 神秘男孩（时间向导）

### 人物档案

| 项目 | 内容 |
|------|------|
| **姓名** | ？？？（玩家可以自己为他命名） |
| **年龄** | 看起来 10 岁左右 |
| **身份** | 不明。他穿着和 2008 年的林瑜一样的校服，但那张脸总是模糊的——像是相机没对准焦距。 |
| **外貌** | 瘦小的身形，校服洗得发白。看不清五官，但声音很清晰——一种不属于 8 岁孩子的、平静到近乎冷漠的语调。他的影子在正午阳光下比正常人长一倍。 |
| **性格** | 冷静、神秘、话里有话。他知道一些事情，但不直接告诉你。他是引导者，不是拯救者。 |
| **与林瑜的关系** | 他像是 2008 年的林瑜的一个影子——或者说，是 2008 年的世界的守护者。他知道「回来」是怎么回事。 |
| **梦核设定** | 他是这个世界里唯一一个意识到「时间出了错」的存在。他不是 NPC，他是管理员。 |

### 完整对话树

#### 触发条件：在游乐场遇到（第三章核心对话）

```
[第一次遇见]
（神秘男孩坐在秋千上，轻轻地晃着。他没有看你）
男孩：你来了。
林瑜：你是谁？
男孩：（轻轻笑了一下）你心里有一个答案的。说出来吧。
  → 选项 A：你是……小时候的我？
  → 选项 B：你是这个梦的守护者？
  → 选项 C：我不知道

（无论选哪个，他都不会直接回答）

男孩：这不重要。重要的是——你为什么回来？
林瑜：我不知道……我一觉醒来就在这里了。
男孩：没有人会「不小心」回到这里。是你想回来的。
      你的心比你的脑子先做了决定。

[对话推进]
林瑜：这里的一切……都和我记忆中的一模一样。但又有哪里不对。
男孩：（从秋千上跳下来）当然不对。因为这不是 2008 年。
      这是你记忆中的 2008 年。不一样的事物被留下了，不重要的
      被忘记了。这里不是真实的世界——这里是你的心。

[追问]
林瑜：那……我怎么才能回去？
男孩：你随时都可以回去。你只需要闭上眼睛，数到三。
      （停顿）但你还没准备好，是吗？
林瑜：（沉默）
男孩：没关系。反正……时间在这里是静止的。
      你想待多久都可以。
      （走开两步，又回头）不过别待太久。待久了，你会不想走的。

[最终对话（离开游乐场前）]
（男孩站在游乐场的出口，像是在等你）
男孩：你要走了？
林瑜：嗯。该回去了。
男孩：（点点头）找到你想找的东西了吗？
  → 选项 A：找到了……也说不清楚找到了什么
  → 选项 B：没有。但我好像没那么难过了

[选项 A - 模糊的答案]
男孩：（轻轻笑了一下）那就够了。有时候说不清楚的东西，
        才是最重要的。
        走吧。别回头。

[选项 B - 不那么难过了]
男孩：（第一次转头看了你一眼——他的脸还是模糊的，但你能
        感觉到他在笑）那就好。那就没有白回来一趟。

[真正的告别]
（男孩退后一步，阳光在他身后拉出一道长长的影子）
男孩：下次再来的话……我可能就不在这里了。
林瑜：为什么？
男孩：因为你会好好的了。不需要再回来了。
      （他的声音开始变远）林瑜——
      （他叫了你的名字——这是第一次）
      ——谢谢你回来。

（然后他不见了。秋千还在轻轻地晃着。）
```
### 行为逻辑
- 他只出现在游乐场范围内
- 他的语言风格不同于其他所有 NPC——更抽象、更像成年人在说话
- 他称呼林瑜的方式会变化：从「你」到直接叫名字，标志着关系的递进
- **梦核提示**：在最终对话后回到秋千处，会发现秋千的座位上放着一颗透明弹珠，里面有蓝色花瓣——和你口袋里那颗一模一样，但它是另一颗。
