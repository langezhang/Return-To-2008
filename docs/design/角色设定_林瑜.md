## 外貌特征

- **身高**：163cm
- **体型**：偏瘦，长期久坐导致的轻微驼背
- **面容**：五官清秀，但常年熬夜面色偏暗。眼睛不大但很亮，笑起来会眯成月牙。左脸颊有一颗小痣。
- **发型**：及肩黑发，经常扎成低马尾，发尾有些分叉——一直说要去剪但一直没时间。
- **穿着**：工作日穿通勤装（白衬衫+长裤+平底鞋），休息日穿宽松T恤和旧牛仔裤。有一件穿了八年的牛仔外套，袖口已经磨白了，但舍不得扔。
- **标志性特征**：右手腕上戴着一根褪色的红绳编手链，是小学最好的朋友送的，一直没摘下来过。

## 性格特征

### 表层性格（对外）

- **温和友善**：同事眼中好说话的「小林子」，对谁都客客气气，从不主动冲突。
- **责任心强**：工作交给她就让人放心，但也因此常常被塞额外任务。
- **略显内向**：开会时不太主动发言，能用文字说的事绝不当面讲。朋友圈三天可见，发的内容基本是工作转发。

### 深层性格（内心）

- **过度思虑**：入睡前会在脑子里反复回放白天说过的每一句话、做过的每一个决定，担心自己哪里做得不够好。
- **隐藏的理想主义**：表面上接受了自己是「普通打工人」的事实，但内心深处仍然保留着小时候那些不切实际的梦想——背包环游世界、学画画、开一家小书店。
- **情感压抑**：不擅长表达负面情绪，难过的时候会把自己藏起来。上一次哭是半年前，因为加班到凌晨回家发现外卖被保安误收了，坐在楼下的长椅上无声地掉了五分钟眼泪，然后上楼洗洗睡了。
- **念旧**：手机里存着 2018 年以来的所有照片，某云盘里有一个文件夹叫「过去」，里面是从小学到大学的各种碎片。偶尔会在深夜翻看，然后带着复杂的心情入睡。

## 成长背景

### 家庭

- **父亲**：林建国，普通工薪阶层，在本地一家机械厂做了大半辈子技术工。沉默寡言，爱的方式是「多吃饭」「多穿点」「钱够不够花」。2019 年因工厂效益不好被裁员，现在在老家做保安。
- **母亲**：赵秀兰，家庭主妇，后来在超市做收银员到退休。典型的中国式母亲——嘴硬心软，催婚但也会偷偷给你塞钱。2023 年查出腰椎间盘突出，行动不如从前。
- **家庭关系**：不算亲近但也不疏远。每周打一次视频电话，话题永远是「吃了没」「天冷了加衣服」「有没有对象」。林瑜爱他们，但不知道如何表达，就像他们也不知道如何表达一样。

### 童年（2000-2012）

- **8 岁前**：住在南昌老城区的单位家属院，是故事中「2008 年夏天」发生的背景地。那时候的暑假很长、蝉鸣很响、快乐很简单。爸爸会骑二八大杠送她上学，妈妈会在厨房一边炒菜一边喊她写作业。
- **小学**：成绩中上，不是最拔尖的那一个，但老师都喜欢她——乖、听话、作业按时交。最好的朋友叫周小萌，六年级时周小萌家搬去了深圳，之后慢慢断了联系。
- **初中**：开始听周杰伦、许嵩，用 QQ 空间写日志，火星文签名档是「ˊ埖開埖落、誰的過愙」。追过《快乐星球》和《一起来看流星雨》，攒零花钱买过《最小说》。
- **高中**：选了文科，成绩稳定在年级前 30%。高考考了 568 分，去了上海的一所普通一本。爸妈很高兴，摆了谢师宴。

### 成年（2018-2026）

- **大学**：学的是市场营销，不讨厌也不热爱。大四在互联网公司实习，毕业后顺理成章转正。
- **工作八年**：从运营助理做到运营专员，中间跳过一次槽。工资从 6k 涨到了 14k，在上海刚好够活。租住在公司附近的一个老小区的隔断间里，月租 3200。
- **感情状态**：大学谈过一次恋爱，毕业后异地半年分手了。之后相过两次亲，都不了了之。不是不想谈，是「没有力气再去认识一个新的人，从头交代自己的人生」。
- **目前的困境**：对工作感到倦怠，对未来感到迷茫。每天通勤两小时，做八小时的报表和方案，回家刷两小时短视频然后睡觉。周末只想躺着。偶尔想到 8 岁时的自己——那个觉得长大了会变成很厉害的人的自己——会有一种说不清的愧疚感。

## 人物弧光（故事中的成长）

| 阶段 | 状态 |
|------|------|
| **故事开始时** | 疲惫、麻木、对未来失去期待。26 岁的林瑜已经接受了「自己只是一个普通人」这件事。 |
| **序章（回到 2008）** | 困惑、不安。熟悉的房间变得陌生。她不理解发生了什么，但身体的记忆比大脑更快地认出了这个地方。 |
| **第一章·房间** | 试探、回忆。触摸每一个物件，听到妈妈的声音从厨房传来。她开始意识到——她不只想回来看看。 |
| **第二章·街道** | 沉浸、追寻。走在记忆中的街道上，见到熟悉的人。与 NPC 的对话慢慢松动她内心那层坚硬的壳。 |
| **第三章·游乐场** | 面对、释放。在游乐场里她终于承认：她怀念的不是 2008 年，而是那个对未来充满期待的自己。 |
| **终章** | 和解、重生。带着这段记忆回到 2026，她仍然要面对那些报表和通勤，但有什么东西不一样了。她重新开始画画了。 |

## 口头禅/习惯

- 紧张的时候会无意识地转笔
- 说「没事」的频率极高——高兴说没事，难过也说没事
- 喜欢在句子末尾加「……吧」，表现出一种不确定感（「应该可以吧」「好像是吧」）
- 笑的时候会先低头再抬头，像是不太习惯被看到开心的样子
